# Sports API examples

Small, ready-to-run projects built on the **[Sports Information API on RapidAPI](https://rapidapi.com/belchiorarkad-FqvHs2EDOtP/api/sports-information)**. Get a free key there, then set it as `RAPIDAPI_KEY`.

| File | What it does | Language |
|---|---|---|
| [`live-scoreboard.js`](live-scoreboard.js) | Live scores for any sport in your terminal, refreshed every 30 s | Node.js 18+ |
| [`predictions_report.py`](predictions_report.py) | Win probabilities, projected scores and confidence for a day of games (NFL, NBA, soccer...) | Python |
| [`discord-score-bot.js`](discord-score-bot.js) | Discord bot that posts final scores when games end | Node.js + discord.js |
| [`team_schedule_to_ics.py`](team_schedule_to_ics.py) | Export any team's schedule to an `.ics` calendar file | Python |
| [`scores-widget.html`](scores-widget.html) | Embeddable "today's games" widget for your website | HTML / JS |

More ideas: fantasy sports assistant (`/players/:id/gamelog`, `/injuries`), odds tracker (`/odds/:id`, `/futures`), college recruiting tracker (`/cfb/player-rankings`), F1 / golf / UFC event trackers. See the [main README](../README.md) and the [full endpoint reference](../ENDPOINTS.md).
